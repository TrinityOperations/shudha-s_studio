# Shudha's Studio

Website and owner dashboard for Shudha's Studio, a Melbourne personalised-gift maker.

- Requirements: [`docs/SRS.md`](docs/SRS.md)
- Coding rules and stack (read before working, Claude Code reads it automatically): [`CLAUDE.md`](CLAUDE.md)
- Decisions log: [`docs/DECISIONS.md`](docs/DECISIONS.md)
- Work is tracked in GitHub Issues #1–#16, in build order. Start with #1 (Foundation).

## Local setup
1. Copy `.env.example` to `.env.local` and fill in the keys (ask Sayek for the shared vault). Never commit `.env.local`.
2. Setup commands will be added here by the Foundation issue (#1).
